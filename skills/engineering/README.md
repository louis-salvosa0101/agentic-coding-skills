# Engineering

## User-invoked

- [grill-with-docs](./grill-with-docs/SKILL.md): Clarify a change while updating the domain model.
- [setup-skills](./setup-skills/SKILL.md): Configure the project issue tracker, triage labels, and domain-doc layout.
- [to-spec](./to-spec/SKILL.md): Turn the current conversation into a specification and publish it.
- [to-tickets](./to-tickets/SKILL.md): Split a plan or specification into blocked tracer-bullet tickets.
- [implement](./implement/SKILL.md): Build a specification or ticket with TDD and code review.
- [triage](./triage/SKILL.md): Move incoming issues through triage roles.

## Model-invoked

- [diagnosing-bugs](./diagnosing-bugs/SKILL.md): Diagnose hard bugs and performance regressions.
- [research](./research/SKILL.md): Research against primary sources and record cited findings.
- [tdd](./tdd/SKILL.md): Build vertical slices through a red-green loop.
- [domain-modeling](./domain-modeling/SKILL.md): Build and sharpen the domain glossary and ADRs.
- [codebase-design](./codebase-design/SKILL.md): Design deep modules, interfaces, and seams.
- [code-review](./code-review/SKILL.md): Review a diff against standards and its specification.
